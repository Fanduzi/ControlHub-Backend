# Issue Tracker

## Tracker

ControlHub Backend tracks work in GitHub Issues for
`Fanduzi/ControlHub-Backend`, using the `gh` CLI.

## Intake

Issues are the planning and delivery intake surface. Pull requests are not an
external triage queue. Create agent-ready implementation work only after its
specification is accepted and apply the `ready-for-agent` label.

## Publication Safety

Before publishing any security-sensitive design or finding, confirm that its
wording does not expose credentials, production identities, raw protected
content, or exploitable implementation details.
