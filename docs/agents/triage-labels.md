# Triage Labels

Use these canonical GitHub labels without aliases:

| Role | Label |
| --- | --- |
| Needs initial classification | `needs-triage` |
| Needs reporter clarification | `needs-info` |
| Ready for agent implementation | `ready-for-agent` |
| Ready for human decision or review | `ready-for-human` |
| Will not be worked | `wontfix` |
